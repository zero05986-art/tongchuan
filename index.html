想听懂什么？

外语实时转成自然的中文字幕。每次都会自动保存成一条记录，结束后可以一键生成复习笔记，还能针对内容提问。

还没设置翻译服务。点左下角 ⚙︎ 设置，填上 API Key（推荐用 DeepSeek）。
这个浏览器不支持语音识别，只能查看旧记录。电脑请用 Chrome、Edge 或 Safari，iPhone/iPad 用 Safari，安卓用 Chrome。
小贴士
· 设备要放在能听清声音的位置。看番时用外放，或者用另一台设备来听。
· 电脑上用 Chrome 看番？用左下角“🎬 网页字幕”装一个书签按钮，直接识别视频声音，戴耳机也能用。
· 记录保存在这台设备的浏览器里，换设备不会同步。可以在“备份/恢复”里导出再导入。
· iPhone/iPad 建议“添加到主屏幕”使用，Safari 才不会自动清掉旧记录。

设置

API Key 只保存在这台设备的浏览器里。每台设备都要各填一次。

🎬 看番字幕按钮（电脑版 Chrome / Edge）

装好以后，在任何正在放视频的网页上点一下，就能直接识别视频里的声音，在画面下方显示中文字幕。不用麦克风，戴耳机也行，全屏时也能显示。

  1. 先把书签栏显示出来：Mac 按 ⌘ + Shift + B，Windows 按 Ctrl + Shift + B。
  2. 用鼠标把下面这个按钮拖到书签栏上，然后松开：
    🎬 看番字幕
    还没在“设置”里填 API Key，装好后需要在每个网站的面板里点 ⚙ 填一次。
  3. 打开视频网页，先让视频开始播放，再点书签栏上的「看番字幕」。右下角会出现控制面板，点开始。

面板按钮：开始/暂停 · 切换语言（日语→韩语→英语→中文） · 原文显示开关 · A−/A+ 字号 · ⚙ 设置 · ✕ 关闭。再点一次书签可以隐藏或显示面板。

拖不动？点“复制按钮代码”，然后在书签栏上右键 →“添加网页”，名称填“看番字幕”，网址那一栏粘贴进去，保存即可。

说明：视频放在别的网站的内嵌播放器里，或者有版权加密时，可能拿不到声音，状态栏会提示；这时可以改用本 App 的麦克风模式（电脑外放）。改了 API Key 以后要重新拖一次按钮。

备份与恢复

记录只存在这台设备上。可以导出一个备份文件，然后在别的设备上导入；导入时会合并，不会覆盖已有的记录。
